# Immersive About Page Redesign

## Goal
Transform the existing About page into a visually richer founder-led story while preserving the homepage’s established Design Diaries identity, real content, facts, imagery, recognition data, and enquiry path.

## What will change
- Recompose the opening into a cinematic founder introduction with layered Sagrika and gym-project visuals, compact statement typography, and clear studio positioning.
- Turn the existing journey into an image-led editorial timeline so every milestone has stronger visual context and a clearer reading sequence.
- Add an immersive founder-story chapter using the existing portrait, studio beliefs, project imagery, and movement-focused design philosophy.
- Rework the philosophy area into a more art-directed visual composition with project details, floor-plan imagery, interactive emphasis, and restrained hover movement.
- Elevate awards and press with the existing moving brand-logo strip, a stronger recognition ledger, and richer dark-page composition.
- Restyle the social/project gallery, proof metrics, and final enquiry section so the lower page feels intentional rather than repetitive.
- Keep the page responsive across desktop, tablet, and mobile, with no oversized text or excessive empty space.

## Motion and interaction
- Use viewport-entry image masks, staggered text reveals, subtle image parallax/zoom, animated timeline progress, gallery hover states, and moving recognition marks.
- Keep motion calm and premium, pause or simplify where appropriate, and fully respect reduced-motion preferences.

## Technical details
- Build the redesigned composition from reusable About-page sections using current local assets and semantic design tokens.
- Preserve the current About route, metadata, links, brand fonts, black/cream/grey/orange palette, and approximately 60/40 dark-light rhythm.
- Validate desktop, tablet, and mobile layouts, image loading, navigation, horizontal overflow, runtime errors, and the final build.
